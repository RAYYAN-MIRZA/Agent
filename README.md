# Agent

Python **network scan agent** for FYP. Source and docs live under **`fyp_agent/`**.

- **Setup and usage:** [fyp_agent/README.md](fyp_agent/README.md)
- **Sample config:** [fyp_agent/config.sample.yaml](fyp_agent/config.sample.yaml)

Point **`api_base_url`** at your **FYP.Backend** instance (default local dev: **http://localhost:5017**). Use **FYP.UI** in the sibling repo to drive jobs and view results, or the **fyp-testing-lab1** repo for an all-in-one Docker lab.
